GOVERNANCE & DATA INTEGRITY

Security, compliance, and tenant isolation built-in.

How Kindred protects customer data, enforces carrier regulations, and maintains strict multi-tenant boundaries.

01 // ISOLATION

Row-Level Security (RLS)

Every tenant-owned database record carries an explicit organization ID. PostgreSQL RLS policies enforce isolation as an independent defense-in-depth boundary.

02 // REPLAY PROTECTION

Ed25519 Webhook Verification

Inbound webhook callbacks are cryptographically verified using Telnyx official public keys and timestamp replay detection windows.

03 // IMMUTABILITY

Approval Snapshot Locking

Campaign sends lock an immutable recipient and message snapshot. Any copy or audience edit immediately voids prior approval.

04 // AUDIT LOGS

Cryptographic Action Trail

Every administrative action, rate verification, campaign preview, and message dispatch is recorded chronologically without exposing plain text PII.

Mortgage Knowledge & Financial Advice Guardrail

Kindred is engineered specifically for licensed mortgage brokers and lenders. Autonomous agents are prohibited from quoting speculative rates or providing individualized credit decisions. All rate benchmarks in communication templates require dual sign-off from your licensed compliance officer.
